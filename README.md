# Hotel Dining Order Management System

A premium, easy-to-use web application for managing hotel dining orders.

## Features
- **Staff Interface**: Take orders, view menu, track status.
- **Admin Interface**: Manage menu items, view sales history.
- **Backend**: Node.js + Express + SQLite (Database).
- **Design**: Modern Glassmorphism UI.

## Setup Instructions

### 1. Start the Backend Server
The backend handles the database and API.
1. Open a terminal.
2. Navigate to the backend folder:
   ```bash
   cd backend
   ```
3. Install dependencies (first time only):
   ```bash
   npm install
   ```
4. Start the server:
   ```bash
   node server.js
   ```
   *The server runs on http://localhost:3000*

### 2. Run the Frontend
1. Go to the `frontend` folder.
2. Open `index.html` in your web browser.
